# Bird & Vine Plates — bird library sources

All 35 birds are public-domain watercolours from the Rijksmuseum, Amsterdam (Public Domain Mark 1.0).
Artists: Robert Jacob Gordon (Cape Colony, 1777–86), Anselmus Boëtius de Boodt (bird albums for Rudolf II, 1596–1610), Jan Brandes (1785–87) and Johannes Bronkhorst (c. 1675–1726).
Processing for every image: background removed with rembg (isnet-general-use), painted perches masked by hand, white point lifted, resized, saved as WebP.
